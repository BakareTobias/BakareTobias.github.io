Computer vision, Machine learning, Web app

American Sign Language Interface

A real-time American Sign Language recognizer built on MediaPipe hand landmarks. Random Forest and Logistic Regression classifiers cover 26+ gesture classes, and an LSTM handles the letters that need motion, like J and Z. It runs live in the browser through a Streamlit and WebRTC front end.

About
